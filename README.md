# Vacio.

Vacio. is an independent digital studio in Dehradun, India, building websites, content and practical digital tools for businesses and emerging brands.

## Stack

- React 19 + Vite 8
- Plain CSS
- Formspree contact form
- Deployed on Vercel

## Scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run lint` — run ESLint
- `npm run preview` — preview the production build locally

## Contact form

The contact form posts to the Formspree endpoint defined in `src/components/ContactSection.jsx`.
